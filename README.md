# Филипп

Сайт персонажа для кампании «Проклятие Страда»: https://legendpsy.github.io/dnd-filipp/

- `index.html` — главная, выбор из трёх карт.
- `players/` — «Странник в углу таверны», открыта всем: только то, что видно в таверне.
- `levels/2/` … `levels/9/` — страницы памяти, открываются по одной с каждым новым уровнем, у каждой свой пароль.
- `book/` — повесть «Руки должны быть чистыми», открывается на 10 уровне.
- `master/` — досье для мастера, под отдельным паролем.
- `img/` — арты (Scenario).

Страницы памяти, повесть и досье для мастера зашифрованы (PBKDF2 + AES-GCM). В файлах лежит только шифр, открытого текста там нет. Пароль в репозитории не хранится.
