# Филипп

Сайт персонажа для кампании «Проклятие Страда»: https://legendpsy.github.io/dnd-filipp/

- `index.html` — главная, выбор из трёх карт.
- `players/` — страница для игроков, открыта всем.
- `book/` — повесть «Руки должны быть чистыми», под паролем.
- `master/` — досье для мастера, под паролем.
- `img/` — арты (Scenario).

Повесть и досье для мастера зашифрованы (PBKDF2 + AES-GCM). В файлах лежит только шифр, открытого текста там нет. Пароль в репозитории не хранится.
