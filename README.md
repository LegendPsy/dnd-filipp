# Филипп

Сайт персонажа для кампании «Проклятие Страда»: https://legendpsy.github.io/dnd-filipp/

- `index.html` — главная, выбор из двух карт.
- `players/` — «Знакомьтесь — Филипп» (таверна), открыта всем: только то, что видно в таверне.
- `levels/2/` … `levels/9/` — страницы памяти, открываются по одной с каждым новым уровнем, у каждой свой пароль.
- `book/` — повесть «Руки должны быть чистыми», открывается на 10 уровне.
- Досье для мастера лежит по отдельной ссылке, с главной на него не попасть.
- `img/` — арты (Scenario).

Страницы памяти и повесть открываются по ходу игры, до этого вместо них заставка «Пока закрыто».
